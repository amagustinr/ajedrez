# Ajedrez de bolsillo

Ajedrez para el móvil: contra un bot (Fácil, Medio, Difícil) o a dos jugadores en el mismo teléfono.
Reglas completas: enroque, captura al paso, coronación, jaque mate, ahogado, triple repetición, regla de 50 movimientos y material insuficiente.

Es una PWA (HTML + JavaScript, sin dependencias): se instala desde el navegador y funciona sin conexión.

**Jugar:** https://amagustinr.github.io/ajedrez/

## Instalar en el móvil
- Android (Chrome): menú ⋮ → *Instalar aplicación*.
- iPhone (Safari): Compartir → *Añadir a pantalla de inicio*.
